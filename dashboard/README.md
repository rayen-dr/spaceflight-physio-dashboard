# Dashboard

Streamlit multipage app.
- `app.py` (to be created) — Home page / entry point.
- **pages/** — One file per dashboard page (Bone Health, Muscle Health, Cardiovascular, Sleep, Mission Comparison, Astronaut Comparison, Advanced Analytics).
- **assets/** — Static images/icons used in the dashboard UI.

Run locally with: `streamlit run dashboard/app.py`
